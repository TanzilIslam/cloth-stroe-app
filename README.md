## Scripts
| Command | Does |
|---|---|
| `pnpm dev` | Start the dev server |
| `pnpm validate` | Typecheck → lint → format → build (run before pushing) |
| `pnpm typecheck` | `tsc --noEmit` |
| `pnpm lint` | ESLint |
| `pnpm format` | Prettier write |
| `pnpm build` | Production build |
